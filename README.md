# Azure Terraform & Ansible Lab

## Overview

This project demonstrates and Documents:

- Azure Infrastructure as Code
- Terraform modules
- Azure DevOps CI/CD
- Ansible Configuration Management
- Automated VM provisioning

## Architecture

Terraform:
- Resource Group
- Virtual Network
- Linux VM

Ansible:
- NGINX deployment
- Security hardening
- System updates

## Deployment

terraform init
terraform plan
terraform apply
